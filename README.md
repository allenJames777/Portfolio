# Allen James Lluvido — Portfolio

Personal portfolio site: Workflow Engineer specializing in automation, integrations, and data analytics.

Built with [Next.js](https://nextjs.org) (App Router) and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Editing content

- **Experience (jobs, internships):** `data/experience.js`.
- **Projects (things you built yourself):** `data/projects.js` — thumbnails go in `public/projects/`.
- **Skills:** the `capabilities` array in `components/Skills.js`.
- **Hero / contact:** `components/Hero.js`, `components/Contact.js`.
- **Resume, photo, papers:** files in `public/`.
